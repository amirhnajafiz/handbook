# Two-Phase Commit

## Quick Description (QD)

The **Two-Phase Commit (2PC)** protocol is a distributed algorithm used to ensure all participants in a distributed transaction either commit or abort the transaction, maintaining consistency across the system.

### Key Concepts

- **Coordinator:** The node that manages the commit process.
- **Participant:** Nodes that take part in the transaction and respond to the coordinator.
- **Atomicity:** Ensures that all nodes agree on the outcome (commit or abort).

### 2PC Phases

1. **Prepare phase:**
    - The coordinator sends a prepare request to all participants, asking if they can commit.
    - Each participant that votes "Yes" first durably logs that it is prepared, so it can still commit after a crash, and from then on it must wait for the coordinator's decision. A participant that cannot commit votes "No" and can abort right away.

2. **Commit phase:**
    - If all participants vote "Yes," the coordinator logs the decision, then sends a commit message, and all participants commit the transaction.
    - If any participant votes "No" (or does not answer in time), the coordinator sends an abort message, and all participants abort the transaction.
    - Participants acknowledge the decision, after which the coordinator can forget the transaction.

### Safety and Fault Tolerance

- 2PC ensures atomicity but is a blocking protocol: if the coordinator fails after participants have voted "Yes" and before they learn the decision, those participants are in doubt. They must keep their locks and wait until the coordinator recovers.
- 2PC assumes crash failures with recovery from stable storage. It does not handle Byzantine faults.
- Making the commit decision itself fault tolerant is the idea behind Paxos Commit, which replaces the single coordinator decision with a consensus (see [Paxos](02_paxos.md)). Three-phase commit also avoids blocking, but only under stronger timing assumptions.

### Use Cases

- Distributed databases
- Distributed transaction processing
- Financial systems requiring atomic operations
