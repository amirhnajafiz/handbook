## Quick Description (QD)

Tools built with Go:

- Kubernetes: Container orchestration platform for automating deployment, scaling, and management of containerized applications.
- Docker: The leading containerization engine for packaging and running applications (see [Docker](../containers/01_docker.md)).
- etcd: Distributed, reliable key-value store used by Kubernetes.
- Prometheus: Monitoring and alerting toolkit, widely used for metrics collection.
- Grafana: Analytics and monitoring platform (primary backend in Go).
- Consul: Service discovery, configuration, and segmentation tool.
- Terraform: Infrastructure-as-Code tool for provisioning and managing cloud resources.
- Vault: Secrets management system (from HashiCorp).
- Helm: Kubernetes package manager.
- Istio: Service mesh for managing microservices networking.
- containerd: Industry standard container runtime (see [containerd](../containers/02_containerd.md)).
- Podman: Daemonless container engine, an alternative to Docker.
- CRI-O: Lightweight container runtime built specifically for Kubernetes.
- CoreDNS: DNS server and service discovery (used in Kubernetes by default).
- Argo CD: GitOps continuous delivery tool for Kubernetes.

## Installation

```bash
wget https://go.dev/dl/go1.25.0.linux-amd64.tar.gz
sudo rm -rf /usr/local/go && sudo tar -C /usr/local -xzf go1.25.0.linux-amd64.tar.gz
export PATH=$PATH:/usr/local/go/bin
go version
```

Removing any previous `/usr/local/go` first is important, because extracting over an old install can leave stale files. Add the `export` line to `~/.profile` to make it permanent. Pick the version you want from the [downloads page](https://go.dev/dl/).

## Useful Tips/Commands (UToC)

### Manage Packages

Initialize a module (recommended for all projects):

```bash
go mod init <module-name>
```

Add a dependency (or upgrade it to a specific version with `<package>@<version>`):

```bash
go get <package>
```

Update all dependencies of the current module:

```bash
go get -u ./...
```

Tidy up unused dependencies:

```bash
go mod tidy
```

### Compile and Run Projects

Run:

```bash
go run main.go
```

Build:

```bash
go build -o myapp main.go
```

Install the binary of the current package (to `$GOBIN`, which defaults to `$GOPATH/bin`):

```bash
go install .
```

Run tests:

```bash
go test ./...
```

## Examples (e.g.,)

### General File Structure for Modular Apps

```text
myapp/
├── go.mod
├── main.go
├── pkg/
│   └── mylib.go
├── internal/
│   └── secret.go
└── README.md
```

- `go.mod`: Module definition and dependencies
- `main.go`: Entry point
- `pkg/`: Public libraries
- `internal/`: Private code (the compiler only allows importing it from within the parent of `internal/`, i.e., this module)
